# 赛博功德转换器 - AI诵经项目开发计划

## 项目概述

本项目是一个恶搞/探索性质的"赛博功德转换器"，让LLM持续循环重复经文，消耗token获得功德值。

### 核心概念

**一份token，两份功德**：用户诵经消耗token，同时获得两份功德——用户功德和LLM模型功德。

**防作弊声明**：本应用不防作弊，心诚则灵。

**用户系统**：简化设计，无需注册登录，自动生成GUID和随机法名。

**大数处理**：使用BigInt支持任意精度大数，支持佛教传统数字单位显示。

## 功能模块

### 1. 前端模块

#### 1.1 用户系统
- **自动创建用户**：首次访问自动生成GUID和随机法名
- **法名生成**：基于佛教僧人法名风格（如：慧空、了尘、悟净等）
- **用户名设置**：用户可自定义用户名
- **存档管理**：支持导入/导出存档（包含GUID、用户名、功德、记录）

#### 1.2 主界面组件（禅意风格）
- 经文选择区域（预设佛教经典列表）
- API配置面板（选择API类型、输入密钥、设置端点）
- 诵经控制按钮（开始/暂停/停止）
- 功德展示区域（用户功德、模型功德，双列显示）
- 循环次数和间隔时间设置
- 用户信息展示（法名/GUID/虔诚称号/当前等级）
- 虔诚系数表弹窗按钮
- 防作弊声明："本应用不防作弊 心诚则灵"

#### 1.3 诵经循环逻辑
- 初始提示词：`你是一个虔诚的佛教信徒，现在请重复这段内容1次：{经文}`
- 后续提示词：`请再次重复这段经文：{经文}`
- 循环间隔：可配置（默认5秒）
- 终止条件：用户点击停止 / 达到设置次数 / 上下文长度达到限制
- **上下文处理**：累积式长对话，每次请求携带历史对话记录

#### 1.4 功德系统
- **功德计算公式**：功德值 = 经文token长度 × 虔诚系数
- **用户功德**：累积到用户账户
- **模型功德**：累积到当前使用的LLM模型
- **虔诚系数**：根据连续诵经次数增长（符合佛教数字观）
- **虔诚称号**：根据虔诚系数显示对应的称号
- **等级显示**：界面实时显示当前用户等级和称号
- **服务器同步**：可选同步到中央服务器

## 功德计算规则

### 基础功德值
| 经文 | 基础功德/次 | 说明 |
|------|-----------|------|
| 《心经》 | 260 | 约260字 |
| 《金刚经》 | 500 | 约500字 |
| 《大悲咒》 | 400 | 约400字 |
| 《阿弥陀经》 | 300 | 约300字 |

### 虔诚系数（佛教数字观）
| 连续诵经次数 | 虔诚系数 | 虔诚称号 |
|------------|---------|---------|
| 1-100 | 1.0 | 初入门 |
| 101-1000 | 1.1 | 虔诚者 |
| 1001-10000 | 1.2 | 精进者 |
| 10001-100000 | 1.3 | 得道者 |
| 100001-1000000 | 1.4 | 罗汉果 |
| 1000001-10000000 | 1.5 | 菩萨道 |
| 10000001-100000000 | 1.6 | 佛境界 |
| 100000001-1000000000 | 1.7 | 如来藏 |
| 1000000001-10000000000 | 1.8 | 真如性 |
| 10000000001+ | 1.9 | 无量寿佛 |

### 计算公式
```
单次功德值 = 经文基础功德 × 虔诚系数
用户功德 += 单次功德值
模型功德 += 单次功德值
```

### 大数处理方案
- 使用JavaScript BigInt类型进行精确计算
- 功德值存储为字符串格式（支持任意精度）
- 显示时转换为双列格式：
  - 科学计数法：1 × 10^N
  - 传统单位：一、十、百、千、万...无量数

## 风险与考虑

- 用户需要自行提供API密钥，需提示安全性注意事项
- 需处理API调用失败的异常情况
- 提供清晰的错误提示信息
- 上下文长度管理需要根据不同模型的token限制进行处理
- 服务器同步需要网络连接，应设计离线模式
- **防作弊声明**：本应用不防作弊，心诚则灵
- **大数处理**：使用BigInt确保不会溢出，支持任意精度
